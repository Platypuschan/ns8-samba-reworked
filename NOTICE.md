# Attribution

This project is a thin derivative overlay for
[NethServer/ns8-samba](https://github.com/NethServer/ns8-samba), distributed
under GPL-3.0-or-later.

It is an independent community project and is not supported by NethServer or
Nethesis. The resulting module image inherits the official NS8 Samba module
and its runtime images, then adds one CLI provisioning action.
